## How it works

The project is a physical TRNG implemented using ring oscillators.

Four ring oscillators are built from physical SKY130 inverter cells. Each oscillator has a different number of inverters, causing them to oscillate at different frequencies. Their outputs are XORed together to produce an entropy signal based on physical timing variations and oscillator jitter.

The entropy signal is sampled using the project clock and passed through a Von Neumann debiaser to reduce bias. The resulting random bits are collected into an 8-bit random value.

In operation, a new random 8-bit value is generated about every 60 seconds. Test mode allows the generated bytes to be observed continuously without waiting for one minute between outputs.


## How to test

The design can be tested in simulation using GTKWave.

Set:

ui_in[0] = 1 to enable the TRNG

ui_in[1] = 1 to enable test mode

The testbench can then monitor uo_out[7:0] in GTKWave.

For physical testing, collect large number of the 8-bit outputs.


## External hardware

No external hardware is required for the Tiny Tapeout design itself.
